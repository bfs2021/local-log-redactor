# 本地日志脱敏台

一个无需安装依赖的单页日志脱敏工具。打开 [index.html](./index.html) 即可使用。

## 功能

- 对大陆手机号、邮箱、IPv4、Bearer/API 长令牌、PEM 私钥块进行可选脱敏。
- 可添加和逐项移除自定义敏感词，查看各类命中数与处理结果。
- 提供虚构样例、清空、复制结果和下载 TXT 功能。
- 支持窄屏布局；按钮和输入控件可用键盘操作。

## 隐私与离线边界

- 输入内容只在当前页面的 JavaScript 内存中处理。
- 不发送网络请求，不加载远程脚本、字体、图片或其他资源。
- 不使用 Cookie、localStorage、sessionStorage 或 IndexedDB。
- 结果以纯文本写入 textContent，输入内容不会作为 HTML 执行或解析。
- 复制和下载仅在你点击相应按钮后发生；下载文件由浏览器保存。

## 启动

将 index.html 与本说明文件放在同一目录，直接用现代浏览器打开 index.html。无需服务器、构建步骤或依赖安装。若从某些受限预览环境打开，剪贴板权限可能不可用；页面会尝试使用本地复制回退方式。

## 规则与限制

- 手机号：匹配以 1[3-9] 开头的 11 位数字，统一替换为 138****0000。
- 邮箱：以首字符和域名保留部分结构，例如 demo@example.invalid 变为 d***@example.invalid。
- IPv4：匹配并校验四段均不大于 255，替换为文档示例网段 192.0.2.*。
- 令牌：匹配 Bearer 值或常见 API/token 字段中至少 24 位的类密钥字符串，保留少量首尾字符。
- PEM 私钥：将 BEGIN/END 包围的私钥块整体替换为 [REDACTED_PRIVATE_KEY]。
- 自定义词：不区分大小写地逐项匹配，替换为 [REDACTED]。
- 规则是基于正则表达式的启发式处理，可能漏检或误判。复杂格式、换行、编码、内部地址、账号和文件路径需人工检查；不要把未经复核的输出当作安全保证。
